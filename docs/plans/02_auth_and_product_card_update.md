# 온누리스토어 발주관리 - 로그인 및 상품 카드 UI 업데이트 계획

## 1. 변경 배경
- 사용자 요청에 따라 **미인증 사용자의 민감 정보(단가) 열람을 차단**하는 로그인 기능 추가.
- 제품 목록을 `staffmall.janytree.app` 스타일의 **카드 형태 UI**로 변경.
- 각 제품명 하단에 2개의 둥근 아이콘(돋보기, 사진) 추가.

## 2. 세부 구현 계획

### 2.1 인증(Auth) 연동
- 제공된 **Supabase URL 및 Anon Key**를 사용하여 `@supabase/supabase-js` 클라이언트 설정.
- 기존 로컬 저장소 계획에서 **Supabase Auth(이메일/비밀번호)** 를 활용한 인증 방식으로 변경.
- `/login` 라우트를 생성하고, 로그인 폼UI는 `jt-core` 규칙을 따름 (Charcoal 주버튼 사용).

### 2.2 상품 목록 화면 (ItemList)
- `물품등록서_제니트리_온누리스토어_260819.xlsx` 데이터를 런타임에 파싱하여 카드 뷰로 나열.
- **로그인 분기 처리**:
  - 미로그인 시: 가격란에 블러 처리 대신 "🔒 로그인 후 확인" 문구만 명확하게 표시.
  - 미로그인 시: 하단 버튼은 "로그인 후 이용 가능"으로 비활성화 (회색 처리).
  - 로그인 시: 공급가 표시 (소비자가 * 45%), 버튼은 "발주 수량 입력"으로 활성화 (Charcoal 색상).
- **아이콘 버튼 2개 추가**:
  - 돋보기 아이콘 (머티리얼 `search`): 전자라벨 페이지 연동용.
  - 사진 아이콘 (머티리얼 `image`): 상세페이지 연동용.
  - 버튼 클릭 시 기본적으로 `alert` 창을 띄워 작동을 시뮬레이션하며, 추후 실제 URL로 대체.

## 3. 디자인 시스템 (jt-core) 준수 사항
- CSS 토큰: 모든 여백은 `var(--jt-space-*)`, 색상은 `var(--jt-color-*)`, 모서리는 `var(--jt-r-md)` 등 `jt-tokens.css` 값 사용.
- 고정 px 배제하고, `Grid` 레이아웃을 통해 반응형 카드 리스트 구축.
